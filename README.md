# Komentář k zákonu č. 146/2002 Sb., o Státní zemědělské a potravinářské inspekci a o změně některých souvisejících zákonů

Otevřený komentář k zákonu o Státní zemědělské a potravinářské inspekci — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; působnost inspekce, seznam internetových stránek a blokování, oprávnění inspektorů, kontrolní nákup, opatření, zákaz uvádění na trh, krizová situace a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2002-00146_2026-01-01`.
